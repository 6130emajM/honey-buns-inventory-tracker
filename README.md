# Honey Buns Inventory Tracker

A Python command-line project that helps track ingredient quantities and identify items that need restocking.

## Features

- View current ingredient inventory
- Add ingredients and increase quantities
- Remove ingredients while preventing negative stock
- Check for low-stock ingredients

## Technology

- Python 3

## How to Run

Open a terminal in the project folder and run:

```bash
python3 main.py
```

## Sample Data

The inventory quantities and minimum stock levels are sample values created for this portfolio project. They do not represent Honey Buns' actual inventory.
